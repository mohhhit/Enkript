# Quick Start Guide 🚀

## For First-Time Users

### Step 1: Installation
1. Download the APK (Android) or installer (Windows)
2. Install the app on your device
3. Grant necessary permissions when prompted

### Step 2: Initial Setup
1. **Launch Enkript** - You'll see the welcome screen
2. **Create Master Password**
   - Choose a strong, memorable password
   - This encrypts ALL your data
   - **IMPORTANT**: Cannot be recovered if forgotten!
3. **Enable Biometric Auth** (Optional but recommended)
   - Use fingerprint or face recognition
   - Quick access without typing password

### Step 3: Add Your First Credential
1. Tap the **+** button (bottom right)
2. Fill in the form:
   - **App Name**: e.g., "Facebook"
   - **Profile**: e.g., "Personal" or "Work"
   - **Username**: Your email or username
   - **Password**: 
     - Click ⚡ icon to generate strong password
     - Or enter your existing password
3. **Optional fields**:
   - Website URL
   - Category (Social, Banking, etc.)
   - Notes
4. Tap ✓ to save

### Step 4: Access Your Credentials
1. **Search**: Use the search bar to find credentials
2. **Browse**: Scroll through grouped credentials
3. **Filter**: Use category chips (All, Favorites, Social, etc.)

### Step 5: View/Copy Password
1. Tap any credential card
2. Authenticate with biometric/master password
3. Tap 👁️ to reveal password
4. Tap 📋 to copy username, password, or other fields

## Tips & Best Practices

### 🔐 Security Tips
- **Strong Master Password**: Use 12+ characters with mix of types
- **Unique Passwords**: Generate unique passwords for each app
- **Regular Updates**: Change passwords periodically
- **Biometric Lock**: Enable for quick but secure access

### 💡 Pro Tips
- **Favorites**: Star frequently used credentials
- **Categories**: Organize by type for easy access
- **Profiles**: Use multiple profiles for same app (Personal, Work)
- **Password Generator**: Always use "Strong" passwords
- **Cloud Sync**: Enable to backup across devices

### 🎨 Customization
- **Dark Mode**: Settings → Theme → Toggle
- **Categories**: Add custom categories for organization
- **Search**: Quick search by app name, username, or profile

## Troubleshooting

### Forgot Master Password?
- **No recovery possible** - Master password is not stored
- You'll need to reinstall and start fresh
- **Prevention**: Use a memorable but strong password

### Biometric Not Working?
1. Check device has biometric setup (Settings → Security)
2. Ensure app has permission
3. Try re-enabling in Enkript settings

### Can't Find Credential?
1. Use search bar (searches all fields)
2. Check if filter is applied
3. Scroll through app groups

### App Crashes?
1. Update to latest version
2. Clear app cache
3. Report issue with error details
